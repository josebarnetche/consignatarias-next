## Decisiones de producto tomadas HOY (no revertir sin Jose)

1. **PRO Usuario está RETIRADO.** El productor va gratis; revenue = Enterprise API/MCP + PRO
   Consignataria. No construir muros PRO Usuario (`docs/PRO-PRODUCT-STANDARD.md` tiene banner OBSOLETO).
2. **Pricing en ARS, siempre** (Rebill factura ARS). API Starter 74.000 / Growth 451.000 / Scale a
   medida · PRO Consignataria 45.000. **API y Consignataria son productos DISTINTOS**: en /planes van
   separados visualmente (API cielo, Consignataria ámbar) y con precios bien distintos.
3. **Regla datos reales ampliada**: no vender ni mostrar datos que no tenemos (medios de pago) ni
   no verificados (cabezas en el comparador). Ante un feature sobre datos inexistentes → buscar el
   proxy honesto en lo que ya scrapeamos.
4. **Copy: decir menos es más.** Beneficio concreto arriba ("Lo que obtenés:"), sin párrafos.
5. **Onboarding**: nunca mostrar mecánicas (karma) sin explicarlas; el primer render post-signup es
   bienvenida + activación con celebración (chispitas + karma en vivo).

## Gotchas frescos (además de CLAUDE.md)

- `git pull --rebase origin main` SIEMPRE antes de push (el scraper commitea a diario a las 14:00).
- MAG DLLs responden **latin-1**; el índice de arrendamiento se parsea por 4ª celda no-vacía con
  patrón `\d,\d{3}$`. Re-sondear el hub `haciinfo000001` detecta endpoints nuevos.
- `/api/precios` anónimo = 1 req/min (dificulta QA local repetido; usar el MCP para probar data).
- `PriceSparkline` tiene defaults ámbar viejos — pasar `lineColor/areaColor` siempre.
- Dev server: borrar un archivo importado deja el webpack cache roto → `rm -rf .next` + restart;
  `.next/types` de páginas borradas rompe `tsc` → borrar esa carpeta.
- QA con clicks en dev: esperar la hidratación (los clicks pre-hidratación se pierden).
- El deploy tarda ~100s; verificar con un poll de un asset/string nuevo en prod.
- Sin trackear en el repo (preexistente, decidir si se archivan o borran): `debug-2026-05-30/`,
  `geo-audit-2026-05-30/`, `traffic-audit-2026-06-12/`.
