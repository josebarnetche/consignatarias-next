# v1.7.0 Video Catalogs — Technical Design

*Created: 2026-03-15*
*Status: Ready for implementation*

## Overview

Zero-infra-cost video catalog system using YouTube embeds. Consignatarias upload videos to their own YouTube channels, we embed and organize them.

## Data Model

### Supabase Table: `consignataria_videos`

```sql
CREATE TABLE consignataria_videos (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  consignataria_id UUID REFERENCES consignatarias(id) ON DELETE CASCADE,
  youtube_video_id VARCHAR(11) NOT NULL,  -- YouTube video ID
  title VARCHAR(255) NOT NULL,
  description TEXT,
  remate_id INTEGER REFERENCES remates(id) ON DELETE SET NULL,  -- Optional link to auction
  video_type VARCHAR(20) DEFAULT 'remate',  -- 'remate' | 'lote' | 'institucional' | 'tour'
  published_at TIMESTAMP WITH TIME ZONE,  -- YouTube publish date
  thumbnail_url TEXT,  -- Auto-extracted from YouTube
  duration_seconds INTEGER,
  view_count INTEGER DEFAULT 0,  -- Updated via cron
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  is_featured BOOLEAN DEFAULT FALSE,  -- Show prominently
  sort_order INTEGER DEFAULT 0,
  
  UNIQUE(consignataria_id, youtube_video_id)
);

-- Index for profile video galleries
CREATE INDEX idx_videos_consignataria ON consignataria_videos(consignataria_id, is_featured DESC, published_at DESC);

-- Index for auction video lookup
CREATE INDEX idx_videos_remate ON consignataria_videos(remate_id) WHERE remate_id IS NOT NULL;
```

## API Endpoints

### `GET /api/consignatarias/[slug]/videos`
Returns video gallery for a consignataria profile.

```typescript
interface VideoGalleryResponse {
  videos: ConsignatariaVideo[]
  total: number
  hasMore: boolean
}
```

### `POST /api/consignatarias/[slug]/videos` (PRO only)
Add a video by YouTube URL. Auto-fetches metadata from YouTube Data API.

```typescript
interface AddVideoRequest {
  youtubeUrl: string  // Full URL or just video ID
  videoType?: 'remate' | 'lote' | 'institucional' | 'tour'
  remateId?: number  // Link to specific auction
}
```

### `DELETE /api/consignatarias/[slug]/videos/[id]` (PRO only)
Remove a video from the gallery.
