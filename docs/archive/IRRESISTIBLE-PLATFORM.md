# Plataforma Irresistible — Consignatarias.com.ar

> "No se van porque no pueden. No se van porque no quieren."

La meta: que una consignataria que se registra sienta tanto poder que cambiar de plataforma sería perder una ventaja competitiva real.

---

## 🎯 El Modelo Mental

```
CLAIM → WOW → ACTION → HABIT → LOCK-IN → ADVOCACY
  ↓      ↓       ↓        ↓        ↓          ↓
 30s    5min    1day    1week   1month    forever
```

No vendemos software. Vendemos **ventaja competitiva**.

## 💡 PRINCIPIOS CLAVE

1. **Mostrar valor antes de pedir nada**
   - El "wow" viene de datos que YA tienen, no de promesas

2. **Hacer visible lo invisible**
   - "Tenés demanda pero no la ves" → ahora la ves

3. **Acumular valor que no se puede llevar**
   - Cada día que pasa, irse es más costoso

4. **Competencia como motivador**
   - "Tu competidor hizo X" → urgencia real

5. **Status como currency**
   - Rankings, badges, verificación → no se compran, se ganan
